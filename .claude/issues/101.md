`future` is certainly one way to do load balancing in the package. Alternatively, if using the package's default parallel approach with `pbapply`, you can set the load balancing option globally via 

```r
library(pbapply)

# Enable load balancing
pboptions(use_lb = TRUE)

# run either
runSimulation(..., parallel=TRUE)
runArraySimulation(..., parallel=TRUE)
```

From what I recall this will affect the order with which the replicates are evaluated, but they should be the same replicates (just permuted).
